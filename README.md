# 🤖 ربات معاملاتی اتوماتیک بر اساس تاچ سوئینگ‌ها

## Automated Trading Bot Based on Swing Touch Strategy

یک ربات معاملاتی پیشرفته که بر اساس **اصل بازگشت به سوئینگ‌های قبلی** (Swing Retouch Principle) معامله می‌کند.

**اصل اول استراتژی:** تمام سوئینگ‌ها یک بار دیگر تاچ می‌شوند!

## 🎯 معرفی

این ربات با استفاده از یک استراتژی منحصر به فرد بر اساس تحلیل سوئینگ‌های قیمتی و انتظار بازگشت قیمت به سطوح قبلی، معاملات را به صورت خودکار مدیریت می‌کند.

### مفهوم اصلی

در تحلیل تکنیکال، سوئینگ‌ها (نقاط چرخش قیمت) اهمیت زیادی دارند. این ربات بر این باور است که:
> **"هر سوئینگی که در گذشته تشکیل شده، دوباره توسط قیمت تاچ (لمس) خواهد شد"**

این اصل، پایه و اساس تمام تصمیم‌گیری‌های معاملاتی است.

## 🎲 استراتژی معاملاتی

### اصل بنیادین: تاچ مجدد سوئینگ‌ها

```
┌─────────────────────────────────────────────────────────────┐
│  Higher High (HH) ▲                                         │
│         /\        قیمت برمی‌گرده و HH رو تاچ می‌کنه      │
│        /  \                                                 │
│       /    \  ◄── فرصت فروش!                               │
│      /      \                                               │
│                                                             │
│              Lower Low (LL) ▼                              │
│                   /\        قیمت برمی‌گرده و LL رو تاچ     │
│                  /  \       می‌کنه ◄── فرصت خرید!          │
│                 /    \                                      │
└─────────────────────────────────────────────────────────────┘
```

### قوانین معاملاتی

#### 🟢 سیگنال خرید (Buy):
```
شرایط:
  ✓ قیمت به سوئینگ Lower Low قبلی نزدیک شده
  ✓ تلرانس تاچ: ±0.3%

اقدام:
  → ورود به پوزیشن خرید (Long)
  → استاپ لاس زیر Lower Low
  → تیک پرافیت با نسبت 1:2
```

#### 🔴 سیگنال فروش (Sell):
```
شرایط:
  ✓ قیمت به سوئینگ Higher High قبلی نزدیک شده
  ✓ تلرانس تاچ: ±0.3%

اقدام:
  → ورود به پوزیشن فروش (Short)
  → استاپ لاس بالای Higher High
  → تیک پرافیت با نسبت 1:2
```

### زمان‌بندی معاملات

ربات **فقط** در زمان‌های همپوشانی سشن‌های جهانی معامله می‌کند:

```
🌏 سشن آسیا (توکیو):     01:00 - 09:30 (GMT+3)
🌍 سشن اروپا (لندن):      07:00 - 15:30 (GMT+3)
🌎 سشن آمریکا (نیویورک):  18:00 - 02:30 (GMT+3)

📊 همپوشانی‌ها (زمان‌های معامله):

1️⃣  نیویورک-توکیو: 01:00 - 02:30
    - اولویت: متوسط
    - معامله: مجاز ✓

2️⃣  توکیو-لندن: 07:00 - 09:30
    - اولویت: بالا
    - معامله: مجاز ✓

⏸️  زمان استراحت: 15:30 - 18:00
    - اولویت: ندارد
    - معامله: ممنوع ✗
```

## ✨ ویژگی‌ها

### 🔍 تحلیل پیشرفته سوئینگ
- شناسایی خودکار سوئینگ های سقف (Swing Highs)
- شناسایی خودکار سوئینگ های کف (Swing Lows)
- تشخیص الگوهای Higher High و Lower Low
- فیلتر قدرت سوئینگ (حداقل 0.2% تفاوت)
- تأیید سوئینگ با کندل‌های همسایه

### 💰 مدیریت ریسک هوشمند
- محاسبه اتوماتیک اندازه پوزیشن
- استاپ لاس دینامیک با ATR
- نسبت ریسک/ریوارد: 1:2
- محدودیت ضرر روزانه: 7%
- محدودیت ضرر هفتگی: 10%
- محدودیت ضرر ماهانه: 15%
- Trailing Stop: 2%

### 📊 ویژگی‌های معاملاتی
- تلرانس تاچ سوئینگ: 0.3%
- بازه بررسی: 50 کندل گذشته
- حداقل فاصله بین سوئینگ‌ها: 5 کندل
- حداکثر عمر سوئینگ: 100 کندل
- حداکثر پوزیشن‌های باز: 3

### 🛠️ قابلیت‌های فنی
- ماژولار و قابل توسعه
- لاگ جامع تمام فعالیت‌ها
- حالت آزمایشی و Paper Trading
- پشتیبانی از صرافی‌های مختلف (CCXT)
- آمار و گزارش‌دهی کامل

## ⚙️ نحوه کار

### مرحله 1: بررسی زمان ⏰
```python
if زمان_فعلی in [نیویورک-توکیو, توکیو-لندن]:
    ادامه به تحلیل
elif زمان_فعلی == زمان_استراحت:
    هیچ معامله‌ای نکن
```

### مرحله 2: تحلیل سوئینگ‌ها 📈
```python
# شناسایی سوئینگ‌ها در 50 کندل اخیر
swing_highs = پیدا_کردن_سقف_ها()
swing_lows = پیدا_کردن_کف_ها()

# تشخیص الگوها
higher_highs = شناسایی_HH()
lower_lows = شناسایی_LL()
```

### مرحله 3: بررسی تاچ 🎯
```python
قیمت_فعلی = آخرین_قیمت()

for swing in higher_highs:
    if فاصله(قیمت_فعلی, swing.price) <= 0.3%:
        سیگنال_فروش()

for swing in lower_lows:
    if فاصله(قیمت_فعلی, swing.price) <= 0.3%:
        سیگنال_خرید()
```

### مرحله 4: اجرای معامله 💹
```python
if سیگنال == 'buy':
    entry = قیمت_فعلی
    stop_loss = swing_level - (ATR × 1.5)
    take_profit = entry + ((entry - stop_loss) × 2)

elif سیگنال == 'sell':
    entry = قیمت_فعلی
    stop_loss = swing_level + (ATR × 1.5)
    take_profit = entry - ((stop_loss - entry) × 2)
```

## 📊 مثال کامل معامله

### سناریو: تاچ Lower Low

```
📅 تاریخ: 2024-11-09
⏰ زمان: 08:30 (همپوشانی توکیو-لندن)

📊 تحلیل سوئینگ:
   - آخرین Lower Low: $49,500
   - قیمت فعلی: $49,520
   - فاصله: 0.04% ✓ (< 0.3%)
   - قدرت سوئینگ: 0.35% ✓ (> 0.2%)

🟢 سیگنال: خرید
💰 موجودی: 1,000 USDT
📊 ATR: $150

محاسبات:
├─ قیمت ورود: $49,520
├─ استاپ لاس: $49,520 - ($150 × 1.5) = $49,295
├─ فاصله ریسک: $225
├─ ریسک مجاز: $50 (5% از 1,000)
├─ اندازه پوزیشن: $50 / $225 = 0.222 BTC
├─ تیک پرافیت: $49,520 + ($225 × 2) = $49,970

✅ نتیجه: قیمت به $49,970 رسید
💵 سود: ($49,970 - $49,520) × 0.222 = $100
📈 بازدهی: +10%
```

## 🎓 درک استراتژی

### چرا این استراتژی کار می‌کند؟

1. **حافظه بازار**: بازار سطوح قیمتی قبلی را به خاطر می‌سپارد
2. **Support/Resistance**: سوئینگ‌ها به حمایت و مقاومت تبدیل می‌شوند
3. **جذابیت نقدینگی**: معامله‌گران بزرگ در این سطوح منتظرند
4. **احتمال بالای واکنش**: قیمت معمولاً در این نقاط واکنش نشان می‌دهد

### محدودیت‌های استراتژی

- ✗ در بازارهای خیلی رنج یا خیلی ترند ممکن است ضعیف عمل کند
- ✗ نیاز به تنظیمات دقیق دارد
- ✗ در نوسانات شدید ممکن است استاپ بخورد
- ✓ در بازارهای نرمال و با نقدینگی خوب عمل می‌کند
