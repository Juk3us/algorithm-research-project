# 🤖 ایجنت هوشمند دایرکت اینستاگرام

یک سیستم هوشمند مبتنی بر AI برای مدیریت و پاسخگویی خودکار به دایرکت‌های اینستاگرام با هدف فروش محصولات

## ✨ امکانات

- 🔐 **ورود امن به اینستاگرام** با یوزرنیم و پسورد
- 💬 **مشاهده و مدیریت دایرکت‌ها** به صورت زنده
- 🧠 **پاسخگویی هوشمند با AI** (Claude یا OpenAI)
- 📚 **آموزش ایجنت** با متن یا فایل صوتی
- 🎯 **استراتژی فروش 5 مرحله‌ای** برای تبدیل مشتری
- 📊 **آمار و گزارش‌های تحلیلی** از عملکرد
- 🎨 **رابط کاربری وب زیبا** به زبان فارسی
- 💾 **ذخیره‌سازی مکالمات** در دیتابیس SQLite

## 🏗️ ساختار پروژه

```
algorithm-research-project/
├── backend/
│   ├── app.py                 # سرور اصلی Flask
│   ├── instagram_service.py   # سرویس ارتباط با Instagram
│   ├── ai_service.py          # سرویس هوش مصنوعی
│   └── database_service.py    # سرویس دیتابیس
├── templates/
│   └── index.html             # رابط کاربری وب
├── static/
│   ├── style.css              # استایل‌های CSS
│   └── script.js              # منطق JavaScript
├── database/
│   └── instagram_agent.db     # دیتابیس SQLite (ایجاد خودکار)
├── requirements.txt           # وابستگی‌های Python
├── .env.example               # نمونه تنظیمات محیطی
├── .gitignore                 # فایل‌های ignore شده
└── run.sh                     # اسکریپت اجرای سریع
```

## 📋 پیش‌نیازها

- Python 3.8 یا بالاتر
- یک اکانت اینستاگرام
- کلید API هوش مصنوعی (Claude یا OpenAI)

## 🚀 نصب و راه‌اندازی

### روش 1: استفاده از اسکریپت خودکار

```bash
# دانلود و اجرا
./run.sh
```

### روش 2: نصب دستی

```bash
# 1. ایجاد محیط مجازی
python3 -m venv venv
source venv/bin/activate  # در ویندوز: venv\Scripts\activate

# 2. نصب وابستگی‌ها
pip install -r requirements.txt

# 3. تنظیم متغیرهای محیطی
cp .env.example .env
# فایل .env را ویرایش کرده و کلید API خود را وارد کنید

# 4. اجرای برنامه
cd backend
python app.py
```

## 🔑 تنظیم کلید API

در فایل `.env` یکی از کلیدهای زیر را وارد کنید:

```bash
# برای استفاده از Claude (توصیه می‌شود)
ANTHROPIC_API_KEY=sk-ant-api03-...

# یا برای استفاده از OpenAI
OPENAI_API_KEY=sk-...
```

**نکته:** اگر کلید API ندارید، سیستم به صورت پیش‌فرض از پاسخ‌های از پیش تعریف شده استفاده می‌کند.

## 📖 نحوه استفاده

### 1. ورود به اینستاگرام

1. برنامه را اجرا کنید و به `http://localhost:5000` بروید
2. روی دکمه "ورود به اینستاگرام" کلیک کنید
3. یوزرنیم و پسورد خود را وارد کنید

⚠️ **هشدار امنیتی:** استفاده مستقیم از یوزرنیم و پسورد ممکن است نقض قوانین Instagram باشد. این پروژه فقط برای اهداف آموزشی است.

### 2. آموزش ایجنت

1. به بخش "آموزش ایجنت" بروید
2. اطلاعات محصول خود را وارد کنید:

```
محصول: دوره آموزش برنامه‌نویسی Python
قیمت: 500,000 تومان
مدت دوره: 3 ماه
ویژگی‌ها:
- 50 ساعت ویدیو آموزشی
- پروژه‌های عملی
- پشتیبانی تلگرامی
- گواهینامه معتبر

مزایا:
- یادگیری از صفر تا صد
- پشتیبانی مادام‌العمر
- آپدیت‌های رایگان
```

3. روی "ذخیره اطلاعات آموزشی" کلیک کنید

### 3. مشاهده و پاسخ به دایرکت‌ها

1. به بخش "دایرکت‌ها" بروید
2. لیست دایرکت‌ها را مشاهده کنید
3. روی یک مکالمه کلیک کنید
4. دو گزینه دارید:
   - **پاسخ دستی:** خودتان پیام بنویسید
   - **پاسخ هوشمند:** ایجنت AI به صورت خودکار پاسخ می‌دهد

### 4. فعال‌سازی پاسخگویی خودکار

1. به بخش "تنظیمات" بروید
2. گزینه "پاسخگویی خودکار" را فعال کنید
3. تنظیمات دیگر را تنظیم کنید:
   - تعداد مراحل فروش (پیش‌فرض: 5)
   - تاخیر پاسخ (ثانیه)

## 🎯 استراتژی فروش 5 مرحله‌ای

ایجنت به صورت خودکار مکالمات را در 5 مرحله پیش می‌برد:

1. **مرحله 1 - آشنایی:** سلام گرم و جلب توجه مشتری
2. **مرحله 2 - شناسایی نیاز:** پرسیدن سوالات هوشمندانه
3. **مرحله 3 - ارائه راه‌حل:** معرفی محصول به عنوان راه‌حل
4. **مرحله 4 - رفع اعتراضات:** پاسخ به سوالات و نگرانی‌ها
5. **مرحله 5 - بستن فروش:** پیشنهاد نهایی و دعوت به خرید

## 📊 آمار و گزارش‌ها

در بخش "آمار" می‌توانید موارد زیر را مشاهده کنید:

- تعداد کل مکالمات
- تعداد کل پیام‌ها
- مکالمات امروز
- توزیع مکالمات در هر مرحله
- وضعیت پاسخگویی خودکار

## 🛡️ امنیت و حریم خصوصی

- اطلاعات ورود در session محلی ذخیره می‌شود
- دیتابیس به صورت محلی نگهداری می‌شود
- پیام‌ها رمزنگاری نمی‌شوند (برای استفاده تجاری باید رمزنگاری اضافه شود)
- از Instagram API غیررسمی استفاده می‌شود

⚠️ **توجه:** این پروژه برای اهداف آموزشی و تحقیقاتی است. استفاده تجاری ممکن است نیاز به تایید Instagram داشته باشد.

## 🔧 عیب‌یابی

### خطای ورود به اینستاگرام

اگر نمی‌توانید وارد شوید:
- مطمئن شوید اینترنت شما به Instagram دسترسی دارد
- ممکن است Instagram به تایید هویت نیاز داشته باشد - از اپ موبایل وارد شوید
- اگر خطای "PleaseWaitFewMinutes" دریافت کردید، چند دقیقه صبر کنید

### AI پاسخ نمی‌دهد

- مطمئن شوید کلید API خود را در `.env` تنظیم کرده‌اید
- اگر کلید API ندارید، سیستم از پاسخ‌های پیش‌فرض استفاده می‌کند
- بررسی کنید که اعتبار API شما تمام نشده باشد

### دیتابیس کار نمی‌کند

```bash
# پاک کردن و ایجاد مجدد دیتابیس
rm database/instagram_agent.db
python backend/app.py
```
