# 🤖 ربات معاملاتی اتوماتیک بر اساس سشن‌های جهانی

## Automated Trading Bot Based on Global Trading Sessions

یک ربات معاملاتی هوشمند که بر اساس همپوشانی (overlap) سشن‌های معاملاتی آسیا، اروپا و آمریکا به صورت خودکار معامله می‌کند.

## 🎯 معرفی

این ربات معاملاتی با استفاده از استراتژی خاص بر اساس همپوشانی سشن‌های معاملاتی جهانی (آسیا/توکیو، اروپا/لندن، آمریکا/نیویورک) به صورت اتوماتیک معاملات خرید و فروش انجام می‌دهد.

### مفهوم اصلی

در بازارهای مالی جهانی، زمان‌هایی که دو یا چند بازار بزرگ همزمان باز هستند، نقدینگی و نوسانات بیشتری دارند. این ربات از این همپوشانی‌ها برای شناسایی فرصت‌های معاملاتی استفاده می‌کند.

---

## ✨ ویژگی‌ها

### 🌍 مدیریت سشن‌های جهانی
- **سشن آسیا (توکیو)**: 04:00 - 12:30 (GMT+3)
- **سشن اروپا (لندن)**: 10:00 - 18:30 (GMT+3)
- **سشن آمریکا (نیویورک)**: 21:00 - 05:30 (GMT+3)

### 🔄 تشخیص همپوشانی‌ها
- **توکیو-لندن**: 10:00 - 12:30 (اولویت متوسط)
- **لندن-نیویورک**: 15:00 - 18:30 (اولویت بالا - بیشترین نقدینگی)
- **نیویورک-توکیو**: 04:00 - 05:30 (اولویت پایین)

### 💰 مدیریت ریسک پیشرفته
- محاسبه اتوماتیک اندازه پوزیشن بر اساس ریسک
- استاپ لاس دینامیک با استفاده از ATR
- محدودیت ضرر روزانه، هفتگی و ماهانه
- نسبت ریسک به ریوارد قابل تنظیم
- Trailing Stop برای حفظ سود

### 📊 ویژگی‌های معاملاتی
- تحلیل تکنیکال بر اساس سوئینگ‌ها
- محاسبه momentum و روند
- حداکثر تعداد پوزیشن‌های باز همزمان
- حداقل تغییر قیمت برای ورود به معامله

### 🔒 امنیت و کنترل
- حالت آزمایشی (Test Mode)
- معامله کاغذی (Paper Trading)
- لاگ کامل تمام فعالیت‌ها
- اعتبارسنجی تنظیمات

### 🛠️ قابلیت‌های فنی
- پشتیبانی از صرافی‌های مختلف از طریق CCXT
- مدیریت خطا و تلاش مجدد
- آمار و گزارش‌دهی جامع
- کد تمیز و ماژولار

## ⚙️ نحوه کار

### 1. مانیتورینگ سشن‌ها
ربات به صورت مداوم سشن‌های معاملاتی را رصد می‌کند و زمان‌های همپوشانی را شناسایی می‌کند.

### 2. تحلیل بازار
در زمان همپوشانی:
- داده‌های قیمتی (OHLCV) را دریافت می‌کند
- سوئینگ‌های higher high و lower low را پیدا می‌کند
- روند و momentum را محاسبه می‌کند

### 3. تصمیم‌گیری
بر اساس استراتژی:
- **روند صعودی** → سیگنال فروش (فرض بر اصلاح)
- **روند نزولی** → سیگنال خرید (فرض بر برگشت)

### 4. اجرای معامله
- محاسبه اندازه پوزیشن بر اساس ریسک
- تعیین استاپ لاس و تیک پرافیت
- ثبت سفارش در صرافی

### 5. مدیریت پوزیشن
- رصد مداوم پوزیشن‌های باز
- اجرای استاپ لاس و تیک پرافیت
- به‌روزرسانی Trailing Stop

## 🚀 نصب

### پیش‌نیازها
- Python 3.9 یا بالاتر
- حساب کاربری در صرافی KuCoin (یا صرافی‌های دیگر)
- کلید API صرافی

### مراحل نصب

```bash
# 1. کلون کردن پروژه
git clone https://github.com/yourusername/algorithm-research-project.git
cd algorithm-research-project

# 2. ایجاد محیط مجازی
python -m venv venv

# 3. فعال‌سازی محیط مجازی
# در لینوکس/مک:
source venv/bin/activate
# در ویندوز:
venv\Scripts\activate

# 4. نصب کتابخانه‌ها
pip install -r requirements.txt

# 5. کپی فایل تنظیمات
cp .env.example .env

# 6. ویرایش فایل .env و افزودن کلیدهای API
nano .env
```

## 📚 مستندات

### کلاس‌های اصلی

#### SessionManager
مدیریت سشن‌های معاملاتی و تشخیص همپوشانی‌ها

```python
from session_manager import SessionManager

sm = SessionManager()
should_trade, overlap_info = sm.should_trade()
```

#### RiskManager
مدیریت ریسک، محاسبه پوزیشن و استاپ لاس

```python
from risk_manager import RiskManager

rm = RiskManager()
position_size = rm.calculate_position_size(balance, entry_price, stop_loss)
```

#### TradingBot
ربات اصلی معاملاتی

```python
from trading_bot import TradingBot

bot = TradingBot()
bot.run()  # اجرای مداوم
bot.run_once()  # اجرای یک چرخه
```
