# 🤖 ربات معاملاتی بر اساس سوئینگ‌های سشن‌ها

## Automated Trading Bot Based on Session Swing Retouch Strategy

یک ربات معاملاتی هوشمند که بر اساس **تاچ مجدد سوئینگ‌های سشن‌های قبلی** معامله می‌کند.

**سه اصل بنیادین استراتژی:**

1️⃣  **تمام سوئینگ‌ها دوباره تاچ می‌شوند**

2️⃣  **جهت معامله بر اساس روند در زمان overlap**
- روند صعودی → فروش (انتظار اصلاح)
- روند نزولی → خرید (انتظار برگشت)

3️⃣  **تارگت = سوئینگ‌های سشن قبلی**
- خرید → هدف: سوئینگ highs سشن قبلی
- فروش → هدف: سوئینگ lows سشن قبلی
- وقتی تاچ شد → حذف از جدول

## 🎲 استراتژی

### اصل اول: سوئینگ‌ها دوباره تاچ می‌شوند

```
هر سوئینگی که در یک سشن تشکیل می‌شود،
توسط قیمت در سشن‌های بعدی دوباره لمس (تاچ) خواهد شد.
```

این یعنی:
- سوئینگ highs سشن توکیو → در سشن لندن یا نیویورک تاچ می‌شوند
- سوئینگ lows سشن لندن → در سشن نیویورک یا توکیو تاچ می‌شوند

### اصل دوم: جهت معامله بر اساس روند

در زمان overlap (همپوشانی سشن‌ها):

```
✅ اگر روند صعودی → فروش
   منطق: بعد از صعود، اصلاح می‌آید

✅ اگر روند نزولی → خرید
   منطق: بعد از نزول، برگشت می‌آید
```

**مثال:**
```
زمان: 08:00 (همپوشانی توکیو-لندن)
قیمت در 10 کندل اخیر: 50,000 → 50,500 (صعودی)
نتیجه: سیگنال فروش
```

### اصل سوم: تارگت از سشن قبلی

تارگت معامله = سوئینگ‌های سشن قبلی

```
🔵 سشن لندن:
   سشن قبلی = توکیو

   خرید → تارگت: swing highs توکیو
   فروش → تارگت: swing lows توکیو

🔵 سشن نیویورک:
   سشن قبلی = لندن

   خرید → تارگت: swing highs لندن
   فروش → تارگت: swing lows لندن
```

**وقتی قیمت به تارگت رسید:**
- سوئینگ از جدول حذف می‌شود
- دیگه برای معاملات بعدی استفاده نمی‌شه

## زمان‌بندی معاملات (GMT+3)

```
🌏 سشن آسیا (توکیو):     01:00 - 09:30
🌍 سشن اروپا (لندن):      07:00 - 15:30
🌎 سشن آمریکا (نیویورک):  18:00 - 02:30

📊 زمان‌های معامله (Overlap):

1️⃣  نیویورک-توکیو:  01:00 - 02:30
    ✓ معامله مجاز
    ✓ اولویت: متوسط

2️⃣  توکیو-لندن:  07:00 - 09:30
    ✓ معامله مجاز
    ✓ اولویت: بالا

⏸️  زمان استراحت:  15:30 - 18:00
    ✗ معامله ممنوع
```

## ⚙️ نحوه کار (گام به گام)

### گام 1️⃣: بروزرسانی سوئینگ‌ها

```python
# ربات مداماً سوئینگ‌های هر سشن را بروزرسانی می‌کند
tokyo_swings = {
    'highs': [50200, 50500, 50800],
    'lows': [49800, 49500, 49200]
}

london_swings = {
    'highs': [51000, 51500],
    'lows': [50000, 49700]
}
```

### گام 2️⃣: بررسی Overlap

```python
if زمان_فعلی in [توکیو-لندن, نیویورک-توکیو]:
    ادامه به تحلیل
elif زمان_فعلی == زمان_استراحت:
    هیچ کاری نکن
```

### گام 3️⃣: تشخیص روند

```python
# بررسی 10 کندل اخیر
قیمت_شروع = 50,000
قیمت_فعلی = 50,500
تغییر = +1%  # صعودی

→ روند: Bullish (صعودی)
```

### گام 4️⃣: تعیین جهت

```python
if روند == 'صعودی':
    سیگنال = 'فروش'
    تارگت = swing_lows_سشن_قبلی

elif روند == 'نزولی':
    سیگنال = 'خرید'
    تارگت = swing_highs_سشن_قبلی
```

### گام 5️⃣: اجرای معامله

```python
Entry: 50,500
Target: 49,500 (swing low سشن قبلی)
Stop Loss: 50,750 (ATR-based)
```

### گام 6️⃣: مدیریت تارگت

```python
if قیمت به تارگت رسید:
    بستن معامله با سود
    حذف سوئینگ از جدول
```

## 📊 مثال کامل معامله

### سناریو: سشن لندن صبح

```
⏰ زمان: 08:00 (overlap توکیو-لندن)
📍 سشن فعلی: لندن
📋 سشن قبلی: توکیو

🔍 تحلیل روند:
   10 کندل اخیر: 50,000 → 50,600
   تغییر: +1.2% ✓
   روند: صعودی (Bullish)

💡 تصمیم‌گیری:
   روند صعودی → سیگنال فروش
   دلیل: انتظار اصلاح به سوئینگ‌های توکیو

🎯 سوئینگ‌های توکیو:
   Lows: [49,800, 49,500, 49,200]
   نزدیک‌ترین: 49,800 (فاصله: -800)

📝 معامله:
├─ جهت: فروش
├─ قیمت ورود: 50,600
├─ تارگت: 49,800 (swing low توکیو)
├─ فاصله تا تارگت: 800 ($)
├─ استاپ لاس: 50,850 (ATR × 1.5)
├─ ریسک: 250 ($)
├─ ریوارد: 800 ($)
└─ نسبت: 1:3.2

✅ نتیجه: قیمت به 49,800 رسید
💵 سود: 800 ($)
📊 حذف swing low 49,800 از جدول توکیو
```

## 🎓 درک کامل استراتژی

### چرا این استراتژی منطقی است؟

**1. حافظه بازار:**
- سوئینگ‌ها به Support/Resistance تبدیل می‌شوند
- بازار این سطوح را به یاد می‌آورد

**2. نقدینگی:**
- معامله‌گران بزرگ در سوئینگ‌های قبلی منتظرند
- سفارش‌های زیادی در این سطوح است

**3. رفتار قیمت:**
- قیمت معمولاً به سوئینگ‌ها برمی‌گردد
- واکنش در این نقاط قابل پیش‌بینی‌تر است

**4. روند و اصلاح:**
- بعد از صعود، اصلاح می‌آید
- بعد از نزول، برگشت می‌آید
